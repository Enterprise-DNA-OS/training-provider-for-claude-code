# Customise
Read CLAUDE.md, the current migration, scripts/lib/domain.mjs and scripts/lib/fields.json. Describe the requested change and its effect on existing records. Add a numbered migration; never rewrite an applied migration. Update validation, import mapping, affected views, documents and tests together. Back up real data first. Run npm test against temporary data, then npm run migrate for the authorised database. Add a command when the change creates a recurring job. Do not weaken sourced checks without documenting the new jurisdiction and source. Never send or issue documents.
